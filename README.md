# KeyPulse 사용자 매뉴얼

KeyPulse는 Windows에서 사용할 수 있는 간격 기반 자동 입력 도구입니다.

지정한 프로그램 창이 활성 상태일 때만 키보드 또는 마우스 버튼 입력을 반복 실행할 수 있고, 앱 프로필과 프리셋을 나누어 여러 게임이나 프로그램 설정을 한 파일에서 관리할 수 있습니다.

## 빠른 시작

1. GitHub Releases에서 최신 `KeyPulse.exe`를 다운로드합니다.
2. `KeyPulse.exe`를 실행합니다.
3. `앱 프로필`에서 사용할 프로그램용 프로필을 만들거나 선택합니다.
4. `프로세스 찾기`로 대상 프로그램의 실행 파일명을 선택합니다.
5. `프리셋`을 만들고 `자동 입력`에 입력할 키와 딜레이를 추가합니다.
6. `토글 단축키` 또는 메인 화면의 활성 버튼으로 KeyPulse를 켭니다.

## 핵심 개념

### 앱 프로필

앱 프로필은 대상 프로그램마다 공유되는 실행 조건입니다.

- 대상 프로세스
- 토글 단축키
- 활성 전용 단축키
- 비활성 전용 단축키
- 미니 창 단축키
- 즉시 OFF 키
- 일시정지 키

예를 들어 `Diablo IV` 앱 프로필을 하나 만들면, 여러 프리셋이 같은 대상 프로세스와 단축키 설정을 공유할 수 있습니다.

### 프리셋

프리셋은 실제 자동 입력 목록을 담습니다.

- 자동 입력
- 서브 자동 입력
- 입력 루틴
- 프리셋 설명

프리셋은 순서대로 숫자 단축키 `1~9`가 자동 배정됩니다. KeyPulse 창에 포커스가 있을 때 숫자 키로 프리셋을 전환할 수 있습니다.

## 주요 기능

### 자동 입력

가장 기본적인 자동 입력 기능입니다.

예를 들어 `W`를 `1000ms`로 등록하면 대상 프로그램 창이 활성 상태일 때 1초마다 `W`를 입력합니다.

### 서브 자동 입력

특정 키를 누르고 있는 동안, 토글 ON 상태인 동안, 또는 지정한 횟수만큼 다른 키를 반복 입력합니다.

- `누름`: 시작 키를 누르고 있을 때만 반복합니다.
- `토글`: 시작 키를 누를 때마다 ON/OFF를 전환합니다.
- `횟수 지정`: 시작 키를 한 번 누르면 지정 횟수를 실행하고 종료합니다. 시작 키를 바로 떼어도 계속 실행하며, 실행 중 추가 시작 입력은 무시합니다.
- `대상`: `키 입력`을 선택하면 지정 키를 반복하고, `루틴`을 선택하면 선택한 입력 루틴을 시작 키 조건에 맞춰 실행합니다.
- `비활성 허용`: KeyPulse가 비활성 상태여도 대상 프로그램 창이 활성 상태라면 해당 서브 자동 입력만 동작하게 할 수 있습니다.

입력 루틴을 서브 자동 입력에서만 실행하고 싶다면 해당 루틴의 `활성`은 켜고 `자동 시작`은 끄는 구성이 좋습니다.

횟수를 지정하려면 `방식 → 횟수 지정`을 선택하고 `시작 키`, `입력`, `간격(ms)`, `횟수`를 설정합니다. 예를 들어 `F6 → RMB / 10ms / 5회`는 즉시 첫 탭을 보내고 총 5회 완료 후 멈춥니다. 루틴 대상은 전체 단계 1순회를 1회로 세며 단계별 대기를 사용합니다.

상태 칸에서 `실행 2/5회`, `외부 입력으로 보류 2/5회`, `완료 5/5회`를 확인할 수 있습니다. 외부 동일 키 점유나 처리 지연으로 보류된 입력은 완료 횟수에 포함하지 않습니다. 일시정지·대상 창 이탈·설정 변경으로 중단되면 새로 시작해야 합니다. 시작 키와 출력 키를 다르게 지정하는 것을 권장합니다.

Windows는 down/up 전송이 모두 끝난 탭을 세고 macOS 공통 실행판은 설정된 누름 시간에 따른 해제 완료까지 확인합니다. 설정 간격은 목표 주기이며 macOS의 기존 타이머·누름 시간·해제 뒤 대기로 실제 간격이 길어질 수 있습니다. 완료 횟수는 게임의 스킬 적용 횟수를 측정한 값이 아닙니다. 횟수 지정 설정은 구버전에서 지원되지 않습니다.

### 입력 루틴

여러 단계의 `대기 -> 입력`을 하나의 시퀀스로 묶어 실행합니다.

예를 들어 `0ms 대기 후 W`, `20ms 대기 후 E`, `20ms 대기 후 R`처럼 순서가 중요한 입력을 구성할 수 있습니다.

`자동 시작`이 켜진 루틴은 KeyPulse 활성 상태에서 바로 반복 실행되고, 꺼진 루틴은 서브 자동 입력에서 호출할 때만 실행할 수 있습니다. `활성`이 꺼진 루틴은 어디서도 실행되지 않습니다.

### 즉시 OFF 키

등록한 키를 누르면 KeyPulse를 즉시 비활성화합니다.

문제가 생겼을 때 빠르게 멈출 수 있도록 `B`, `ENTER`, `ESC` 같은 키를 별도로 지정해두는 방식이 좋습니다.

### 일시정지 키

등록한 키를 누르고 있는 동안 자동 입력을 잠시 멈춥니다.

예를 들어 `TAB`을 등록하면 지도나 메뉴를 보는 동안 자동 입력이 멈추도록 구성할 수 있습니다.

### 미니 창

메인 설정창 대신 미니 창으로 전환해 게임이나 프로그램 위에 올려둘 수 있습니다.

- 좌클릭: 활성/비활성 전환
- 드래그: 위치 이동
- 우클릭: 메인뷰 복귀, 트레이 이동, 종료
- 투명도 조절: 메인 옵션 또는 미니 창 overlay에서 조절

### 마우스 버튼 입력

키보드 외에 마우스 버튼도 사용할 수 있습니다.

| 표시 | 의미 |
| --- | --- |
| `LMB` | 마우스 왼쪽 버튼 |
| `RMB` | 마우스 오른쪽 버튼 |
| `MMB` | 마우스 휠 클릭 |
| `X1` | 마우스 보조 버튼 1 |
| `X2` | 마우스 보조 버튼 2 |

마우스 버튼은 일반 클릭과 함께 동작할 수 있으므로, 대상 프로그램에서 의도한 입력인지 먼저 짧게 테스트하는 것을 권장합니다.

## 설정 저장

KeyPulse는 로컬 설정 파일과 클라우드 동기화를 모두 지원합니다.

- 로컬: JSON 설정 파일로 저장합니다.
- 클라우드: 이메일 로그인 후 계정 기준으로 설정을 동기화합니다.

클라우드 모드에서 `다시 받기`를 누르면 현재 로컬 변경사항을 버리고 원격 설정을 다시 불러올 수 있습니다.

## 알림과 상태 표시

알림 방식은 옵션에서 선택할 수 있습니다.

- 사용 안 함
- Windows 알림
- 앱 내부 알림

하단 상태바에는 현재 상태, 프리셋, 대상 프로세스가 표시됩니다. 활성 상태는 녹색, 비활성 상태는 빨간색, 일시정지 상태는 노란색 계열로 구분됩니다.

## 문제 해결

Windows에서 `도움말 → 입력 진단`을 열면 전송 완료·외부 키 보류·실패·회차 생략과 처리 시간을 확인하고 JSON으로 저장할 수 있습니다. 게임의 실제 스킬 효과는 별도로 확인해야 합니다. X1·X2 단축키가 반응하지 않으면 진단 창에서 버튼을 눌렀다 떼며 down/up 수신 횟수가 증가하는지 확인하세요. G HUB가 원래 버튼을 다른 키로 바꾸면 원래 X1·X2 신호가 전달되지 않을 수 있습니다.

- 자동 입력이 안 되면 대상 프로세스명이 정확한지 확인합니다.
- 대상 프로그램 창이 실제 활성 창인지 확인합니다.
- 자동 입력 행의 `활성` 체크가 켜져 있는지 확인합니다.
- 즉시 OFF 키나 일시정지 키가 눌린 상태가 아닌지 확인합니다.
- 필요하면 `디버그 로그 사용`을 켜고 `logs/keypulse.log`를 확인합니다.

## 주의사항

KeyPulse는 개인 자동화와 반복 작업 편의를 위한 도구입니다.

사용 환경과 대상 프로그램의 정책을 반드시 확인한 뒤 사용하세요. 게임이나 프로그램의 이용약관을 위반하거나 다른 사용자에게 피해를 주는 방식으로 사용하는 것은 권장하지 않습니다.
