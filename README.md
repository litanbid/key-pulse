# KeyPulse

간격(Interval) 기반 자동 키 입력 프로그램입니다.

디아블로4 헬퍼 용도로 사용하기 위해 개발을 시작했으며,
현재는 특정 게임이나 프로그램에 종속되지 않는 범용 자동 키 입력 도구 형태로 개발 중입니다.

사용자가 지정한 시간 간격으로 키보드 입력을 자동 수행할 수 있으며,
특정 프로그램 또는 게임 창이 활성화된 상태에서만 동작하도록 사용할 수 있습니다.

## 주요 기능

* 사용자 지정 키 자동 입력
* 입력 간격 설정 지원
* 특정 윈도우 활성화 시에만 동작
* 가볍고 간단한 실행 구조
* 자동 업데이트 지원 예정
